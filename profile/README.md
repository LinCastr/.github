# LinCastr

We bring software to Linux.

LinCastr is an open-source organization focused on porting and building applications for the Linux desktop. Many tools that people rely on every day are either unavailable on Linux or poorly supported there. We work to close that gap with native, well-maintained alternatives and ports.

## What we do

- Port applications and tools to Linux so users don't have to give up their workflow or switch systems
- Build native Linux (maybe also Windows) software that feels at home on the desktop
- Maintain our projects in the open, with clear documentation and a welcoming community

## Our principles

- **Linux first.** We design for Linux users and the diversity of distributions, desktop environments, and display servers they use.
- **Open source.** Our code is public, and anyone can read it, use it, and improve it.
- **Practical over perfect.** We focus on software that works well and solves real problems.
- **Respect for users.** No unnecessary tracking, no bloat, and no lock-in.

Our projects live in the repositories of this organization. Browse them to see what we're currently working on, and star the ones you like to follow their progress.

## Contributing

We welcome contributions of all kinds, whether code, bug reports, testing on different distributions, documentation, translations, or ideas.

1. Find a repository that interests you
2. Check its issues for something to work on, or open a new one to discuss your idea
3. Fork the repository and submit a pull request

Each project has its own contributing guidelines, so please read them before getting started.

## Get in touch

- Open an issue in the relevant repository for bugs and feature requests
- Start a discussion in a repository's Discussions tab for questions and ideas
